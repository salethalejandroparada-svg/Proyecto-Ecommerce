# Proyecto E-Commerce

Proyecto académico para las evidencias de formación SENA.

## Tecnologías
- HTML5
- CSS3
- JavaScript
- MySQL
- Git y GitHub
- Visual Studio Code
- XAMPP

## Funciones
- Catálogo de productos.
- Carrito de compras con localStorage.
- Login demostrativo con validación.
- Panel administrativo.
- Base de datos relacional MySQL.
- Diseño responsive.

## Estructura
- index.html
- login.html
- admin.html
- css/styles.css
- js/app.js
- database/ecommerce.sql

## Git
Después de descomprimir:

    git init
    git add .
    git commit -m "Version inicial del proyecto E-Commerce"
    git branch -M main
    git remote add origin https://github.com/USUARIO/Proyecto-Ecommerce.git
    git push -u origin main

La autenticación actual es demostrativa. Para producción debe implementarse un backend y seguridad del lado del servidor.
